# 🤖 JARVIS Ultimate v2.0

**Полнофункциональный AI-ассистент с возможностями обучения**

JARVIS Ultimate — это продвинутый AI-ассистент, вдохновлённый Джарвисом из "Железного человека". Он сочетает голосовое управление, компьютерное зрение, автоматизацию браузера и интеграцию с популярными сервисами.

## 🚀 Новые возможности v2.0

### 🧠 AI и машинное обучение
- **Vision Module** — анализ скриншотов через GPT-4V, распознавание объектов и текста на экране
- **Pixel Eyes** — GUI автоматизация для игр и приложений без API (OCR + template matching)
- **Hybrid Intent System** — быстрые локальные правила + AI fallback для сложных запросов
- **Sub-Agent Orchestration** — управление подзадачами через других агентов

### 🎤 Голосовое управление
- **Wake Word Detection** — активация по голосовой команде "Привет, Джарвис"
- **Streaming TTS** — потоковый синтез речи с началом воспроизведения до завершения генерации
- **Поддержка OpenAI Whisper** — точное распознавание речи

### 🌐 Автоматизация
- **Browser Automation** — управление браузером через Playwright (поиск, заполнение форм, клики)
- **Confirmation Shell** — безопасное выполнение опасных команд с голосовым подтверждением
- **System Control** — управление громкостью, приложениями, окнами, файлами

### 📊 Мониторинг
- **Live Dashboard** — веб-панель мониторинга в реальном времени (CPU, RAM, Disk, Network)
- **WebSocket Server** — подключение мобильного приложения через QR-код
- **System Metrics** — отслеживание производительности системы

### 🔌 Интеграции
- **Gmail** — отправка и чтение email
- **Google Calendar** — создание и управление событиями
- **Slack** — отправка сообщений и управление каналами
- **Notion** — создание и поиск страниц
- **Smart Home** — интеграция с Home Assistant

## 📦 Установка

### Требования
- Python 3.10+
- Windows 10/11 (основная платформа)
- OpenAI API ключ

### Быстрая установка

```bash
# Клонирование репозитория
git clone https://github.com/Lucifer64-ai/jarvis-ultimate-v2.git
cd jarvis-ultimate-v2

# Создание виртуального окружения
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Linux/Mac

# Установка зависимостей
pip install -r requirements.txt

# Установка Playwright для автоматизации браузера
playwright install chromium

# Настройка переменных окружения
cp .env.example .env
# Отредактируйте .env и добавьте ваш OpenAI API ключ
```

### Запуск

```bash
python main.py
```

## 🎯 Использование

### Голосовые команды

**Базовые:**
- "Привет, Джарвис" — активация
- "Который час?" — время
- "Какая сегодня дата?" — дата
- "Открой браузер" — запуск приложения
- "Громче/Тише" — управление звуком

**Продвинутые:**
- "Посмотри на экран" — анализ текущего состояния экрана
- "Найди кнопку Play" — поиск элемента на экране
- "Открой YouTube и поставь видео на паузу" — автоматизация браузера
- "Отправь email Ивану" — интеграция с Gmail
- "Создай событие в календаре" — интеграция с Google Calendar

### Веб-интерфейс

После запуска откройте браузер:
- **Dashboard**: http://localhost:8000
- **WebSocket**: ws://localhost:8765

### Мобильное приложение

1. Запустите JARVIS на ПК
2. Отсканируйте QR-код в интерфейсе
3. Подключитесь через мобильное приложение

## 🔧 Конфигурация

Создайте файл `.env` в корне проекта:

```env
OPENAI_API_KEY=your-api-key-here
HOME_ASSISTANT_URL=http://localhost:8123
HOME_ASSISTANT_TOKEN=your-token
SLACK_BOT_TOKEN=xoxb-your-token
NOTION_TOKEN=your-token
```

## 📱 Мобильное приложение

Мобильное приложение построено на React Native и позволяет:
- Управлять JARVIS удалённо
- Получать уведомления
- Отправлять голосовые команды
- Просматривать статус системы

### Сборка APK

```bash
cd mobile-app
npm install
cd android
./gradlew assembleRelease
```

APK будет доступен в `android/app/build/outputs/apk/release/`

## 🛠️ Разработка

### Добавление нового модуля

1. Создайте файл в `ai/` или `modules/`
2. Реализуйте класс с методами
3. Добавьте инициализацию в `main.py`
4. Обновите `requirements.txt` при необходимости

### Тестирование

```bash
pytest tests/
```

## 🔒 Безопасность

- Все опасные команды требуют подтверждения
- API ключи хранятся в `.env` (не коммитится в git)
- WebSocket сервер работает только на localhost
- Поддержка SSL/TLS для удалённого доступа
