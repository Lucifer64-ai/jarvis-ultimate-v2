## 🚀 Быстрый старт

### Автоматическая установка (Рекомендуется)

JARVIS может автоматически установить все необходимые компоненты:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Lucifer64-ai/jarvis-ultimate-v2.git
cd jarvis-ultimate-v2

# 2. Запустите автоматическую установку
python scripts/setup_auto.py
```

Скрипт автоматически:
- ✅ Установит все Python зависимости
- ✅ Скачает и установит Ollama (локальная LLM)
- ✅ Загрузит модель llama3.2 для Ollama
- ✅ Установит модели Whisper для распознавания речи
- ✅ Загрузит модель Vosk для офлайн распознавания
- ✅ Настроит wake word "Джарвис"
- ✅ Проверит микрофон

### Запуск

```bash
# Консольный режим
python main.py

# HUD интерфейс (стиль Iron Man)
python main_hud.py
```

## 🧠 Гибридная LLM система

JARVIS использует **гибридную систему** с автоматическим переключением между моделями:

### Режимы работы:

1. **Автоматический режим** (по умолчанию)
   - Если есть OpenAI API ключ → использует ChatGPT
   - Если ключа нет → автоматически переключается на Ollama (локально)
   - Не требует настройки - работает из коробки!

2. **Принудительный режим OpenAI**
   - Установите переменную окружения: `OPENAI_API_KEY=your_key`
   - Или используйте команду: "используй chatgpt"

3. **Принудительный режим Ollama**
   - Команда: "используй локальную модель"
   - Работает полностью офлайн, без API ключей

### Команды управления LLM:

- "используй chatgpt" - переключить на OpenAI
- "используй локальную модель" - переключить на Ollama
- "какая модель активна?" - показать текущий режим
- "какие модели доступны?" - список провайдеров

## 🔧 Конфигурация

### Переменные окружения (.env файл)

```env
# OpenAI API ключ (опционально)
OPENAI_API_KEY=sk-your-key-here

# Режим LLM: auto, openai, ollama
LLM_MODE=auto

# Модель Ollama
OLLAMA_MODEL=llama3.2
```

### Изменение wake word

Отредактируйте `config/wake_word.json`:

```json
{
  "enabled": true,
  "wake_word": "джарвис",
  "alternative_words": ["jarvis", "джар"],
  "sensitivity": 0.5,
  "timeout": 2.0
}
```

## 🐛 Решение проблем

### Микрофон не работает
1. Проверьте подключение микрофона
2. Запустите `python scripts/setup_auto.py` для проверки
3. Убедитесь что Python имеет доступ к микрофону (Windows Settings)

### Ollama не запускается
1. Проверьте что Ollama установлен: `ollama --version`
2. Запустите сервис Ollama
3. Загрузите модель: `ollama pull llama3.2`

### Whisper не загружается
```bash
pip install --upgrade openai-whisper
```

### Vosk не находит модель
Убедитесь что модель загружена в `models/vosk/`:
```bash
python scripts/setup_models.py
```

### OpenAI не работает
1. Проверьте наличие `.env` файла с `OPENAI_API_KEY`
2. Убедитесь что API ключ действителен
3. Проверьте баланс на https://platform.openai.com/account/billing

## 📱 Мобильное приложение

Управляйте JARVIS с телефона через QR-код (как в Steam)!

### Подключение:
1. Запустите JARVIS на компьютере
2. Скачайте мобильное приложение из `mobile-app/`
3. Отсканируйте QR-код из JARVIS камерой телефона
4. Готово! Управление голосом и командами с телефона

### Возможности:
- 🎤 Голосовое управление через микрофон телефона
- 💬 Текстовые команды
- 📊 Мониторинг системы (CPU, RAM, сеть)
- 📝 Лог команд и ответов
- ⚙️ Настройки подключения и LLM режима

### Установка приложения:
```bash
cd mobile-app
npm install
npm run android  # или npm run ios
```
