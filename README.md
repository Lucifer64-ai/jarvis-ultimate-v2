## 📦 Описание

JARVIS Ultimate - это полнофункциональный AI-ассистент, вдохновлённый JARVIS из Iron Man. Система обеспечивает:

- 🎤 **Голосовое управление** - распознавание команд на русском языке
- 🖥️ **Полное управление ПК** - запуск приложений, управление окнами, работа с файлами
- 🎨 **HUD-интерфейс** - голографический оверлей в стиле Iron Man
- 🧠 **AI и ML** - ChatGPT интеграция, ML-классификация команд
- 🏠 **Умный дом** - интеграция с Home Assistant
- 📱 **Мобильное приложение** - управление через смартфон
- ⚡ **Автоматизация** - планировщик задач, макросы, триггеры
- 🔌 **Плагины** - расширяемая архитектура

## 🚀 Возможности

### Системные операции
- Запуск, переключение, закрытие окон
- Управление громкостью (mute/unmute)
- Блокировка экрана, выключение, перезагрузка
- Управление питанием (сон, гибернация)

### Управление файлами
- Поиск файлов по имени и содержимому
- Создание, копирование, перемещение файлов
- Работа с архивами (ZIP, RAR)
- Конвертация форматов (изображения, документы)

### Работа с приложениями
- Запуск приложений по голосовой команде
- Управление браузером (открыть URL, поиск)
- Работа с буфером обмена
- Скриншоты и запись экрана

### AI и машинное обучение
- Интеграция с ChatGPT для сложных запросов
- ML-классификация голосовых команд
- Адаптивное обучение на действиях пользователя
- Распознавание паттернов использования

### Умный дом
- Интеграция с Home Assistant
- Управление устройствами (свет, термостат, замки)
- Создание сцен и автоматизаций
- Мониторинг датчиков

### HUD-интерфейс
- Голографический оверлей в стиле Iron Man
- Отображение системной информации
- Уведомления и статусы
- Анимации и визуальные эффекты

## ⚙️ Установка

### Требования
- Windows 10/11
- Python 3.11+
- Микрофон (для голосового управления)
- 4GB+ RAM

### Шаги установки

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/Lucifer64-ai/jarvis-ultimate-v2.git
cd jarvis-ultimate-v2
```

2. **Установите зависимости**
```bash
pip install -r requirements.txt
```

3. **Настройте конфигурацию**
```bash
cp .env.example .env
# Отредактируйте .env файл
```

4. **Запустите систему**
```bash
python main.py
```

### Сборка EXE-установщика

```bash
# Windows
build\build.bat

# Или PowerShell
build\build.ps1
```

## 🎮 Использование

### Голосовые команды

**Системные:**
- "Запусти [приложение]" - запустить приложение
- "Закрой [окно]" - закрыть окно
- "Выключи компьютер" - выключение ПК
- "Заблокирой экран" - блокировка

**Файлы:**
- "Найди файл [имя]" - поиск файла
- "Создай файл [имя]" - создание файла
- "Сделай скриншот" - скриншот экрана

**AI:**
- "Спроси ChatGPT [вопрос]" - запрос к ChatGPT
- "Что ты умеешь?" - список возможностей

**Умный дом:**
- "Включи свет" - управление светом
- "Установи температуру [значение]" - термостат
- "Активируй сцену [название]" - запуск сцены

### Мобильное приложение

1. Установите приложение на смартфон
2. Отсканируйте QR-код из системного трея
3. Управляйте JARVIS удалённо

## 🔧 Конфигурация

### .env файл

```env
# OpenAI API
OPENAI_API_KEY=your-api-key-here
OPENAI_MODEL=gpt-4

# Home Assistant
HOME_ASSISTANT_URL=http://192.168.1.100:8123
HOME_ASSISTANT_TOKEN=your-token-here

# Голос
VOICE_LANGUAGE=ru-RU
VOICE_SPEED=1.0

# HUD
HUD_ENABLED=true
HUD_OPACITY=0.8
HUD_POSITION=top-right
```
